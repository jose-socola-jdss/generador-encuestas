# Generador De Encuestas

Generador interno de encuestas para equipos de manufactura, calidad, ergonomia y mejora continua.

## Uso

1. `npm install`
2. `npm run dev`

Incluye constructor dinamico, validacion, vista previa, guardado local, lista de encuestas y analitica ficticia precargada.
## Modos de uso

- Desarrollo: `npm install && npm run dev`
- Archivo estatico: ejecuta `npm run build` y abre `index.html` en la raiz del proyecto.
